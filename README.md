# Ambient Ride for Claude Code

Book and manage TADA/Throo rides from Claude Code with the Ambient Ride skill.

## Install

```bash
claude plugin marketplace add mvlchain/ambient-ride-plugin
claude plugin install ride@ambient-ride
```

Run `/ride:setup` in Claude Code. Setup installs the public
`@ambprotocol/ride-cli` package and is safe to run again.
